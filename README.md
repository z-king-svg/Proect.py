Если хотите, чтоб при запуске скрипта, был звук когда сдвигается кубок и картинки про игроков по бокам, то необходимо локально создать папку и назвать её players(ОБЯЗАТЕЛЬНО ТАК!). После ее создания в нее закидываете МАКСИМУМ 1 ЗВУК
и сколько хотите картинок(будут показываться по 4 и меняться при каждом запуске). Удачного пользования!

If you want a sound to play when the trophy and the player images on the sides shift upon launching the script, you need to create a local folder named `players` (it MUST be named exactly that!). Once created, place a MAXIMUM of 1 sound file inside,
along with as many images as you like (they will be displayed in groups of four and rotate each time the script runs). Enjoy!
